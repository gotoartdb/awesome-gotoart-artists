# Contributing

Thank you for helping maintain a useful and respectful directory.

## Inclusion criteria

- The artist must have a currently public GotoArt profile.
- The entry must be factual, concise, and link to the canonical GotoArt profile.
- Do not submit private contact information, unpublished images, copied artwork, or personal data not already intended for public display.

## Suggest a correction

Open an issue with the artist's public profile URL, the field that needs correction, and a short explanation. GotoArt will verify the source before publishing an update.

## Automated updates

The directory is built from GotoArt's public artist API. The build script intentionally removes contact details and social handles before writing the list. Please do not hand-edit generated artist entries; update the approved source profile and then rebuild.
